# GroupSortedList

> Java-коллекция, которая хранит элементы в именованных группах, но предоставляет к ним доступ как к одному непрерывному списку.

## Обзор

**GroupSortedList** — это пользовательская Java-коллекция, созданная для ситуаций, когда данные должны оставаться логически разделёнными на группы, но при этом вести себя как обычный список.

Вместо хранения всех элементов в одном массиве коллекция хранит элементы внутри независимых именованных групп. Каждая группа управляет только своими элементами, а сама коллекция предоставляет единый глобальный индекс поверх всех групп.

Такой подход позволяет сохранить логическую структуру данных, не теряя удобства индексированного доступа.

---

## Возможности

* Именованные группы
* Доступ к группам по имени или индексу
* Глобальная индексация элементов
* Автоматический пересчёт глобальных диапазонов индексов
* Перемещение групп без перестройки всей коллекции
* Основана на `AbstractList`
* Поддерживает сериализацию (`Serializable`)
* Спроектирована как лёгкая и расширяемая коллекция

---

## Пример

```java
GroupSortedList<Integer> list = new GroupSortedList<>();

list.createGroup("Numbers");
list.getGroup("Numbers").put(10);
list.getGroup("Numbers").put(20);

list.createGroup("Other");
list.getGroup("Other").put(30);

System.out.println(list.get(0)); // 10
System.out.println(list.get(1)); // 20
System.out.println(list.get(2)); // 30
```

---

## Внутреннее устройство

Каждая группа хранит собственный набор элементов.

Коллекция автоматически назначает каждой группе диапазон глобальных индексов.

```text
Глобальный список

0 1 2 3 4 5 6 7 8

┌──────────────┐
│ Group A      │
│ Диапазон: 0..2 │
└──────────────┘

┌──────────────┐
│ Group B      │
│ Диапазон: 3..6 │
└──────────────┘

┌──────────────┐
│ Group C      │
│ Диапазон: 7..8 │
└──────────────┘
```

Когда вызывается `get(index)`, коллекция:

1. Находит группу, диапазон которой содержит указанный индекс.
2. Преобразует глобальный индекс в локальный индекс внутри этой группы.
3. Возвращает соответствующий элемент.

---

## Зачем?

Большинство стандартных Java-коллекций хранят все элементы в одной непрерывной структуре.

**GroupSortedList** предназначена для случаев, когда элементы естественным образом разделены на категории, но при этом должны быть доступны как единая коллекция.

Возможные сценарии использования:

* реестры (registries);
* игровые объекты, разделённые по категориям;
* коллекции ресурсов;
* наборы данных с категориями;
* системы плагинов;
* секции конфигурации.
