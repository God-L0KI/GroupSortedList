## Описание

`GroupSortedList` — экспериментальная коллекция Java, объединяющая группированное хранение данных и доступ к ним как к обычному списку.

Вместо хранения всех элементов в одном массиве элементы распределяются по именованным группам, при этом коллекция предоставляет единый глобальный доступ по индексу.

Каждая группа имеет собственный диапазон глобальных индексов, благодаря чему можно сохранить логическую структуру данных и одновременно работать с ними как с обычным `List`.

---

## Возможности

- Именованные группы
- Глобальная индексация
- Доступ к элементам по одному индексу
- Получение группы по имени или индексу
- Перемещение групп без пересоздания коллекции
- Автоматический пересчёт диапазонов индексов
- Serializable
- Основана на `AbstractList`

---

## Пример

```java
GroupSortedList<Integer> list = new GroupSortedList<>();

list.createGroup("First");
list.getGroup("First").put(10);
list.getGroup("First").put(20);

list.createGroup("Second");
list.getGroup("Second").put(30);

System.out.println(list.get(0)); // 10
System.out.println(list.get(1)); // 20
System.out.println(list.get(2)); // 30
```

## Как это работает

Каждая группа хранит собственный набор элементов.

Коллекция автоматически назначает каждой группе диапазон глобальных индексов.

Например:

```
Общий список

0 1 2 3 4 5 6 7 8

┌────────────┐
│ Group A    │
│ 0 1 2      │
└────────────┘

┌────────────┐
│ Group B    │
│ 3 4 5 6    │
└────────────┘

┌────────────┐
│ Group C    │
│ 7 8        │
└────────────┘
```

При вызове `get(index)`:

1. Находится группа, диапазон которой содержит указанный глобальный индекс.
2. Глобальный индекс преобразуется в локальный индекс внутри группы.
3. Возвращается нужный элемент.
